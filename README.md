# srckit-echo

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Send HTTP requests and inspect full responses, or build mock HTTP responses for testing.

## Features

- **Request Echo** — Full HTTP client with method selector, custom headers, request body, and response display with duration and size
- **Response Builder** — Craft mock HTTP responses with status codes, headers, and body for testing webhooks and API clients

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
